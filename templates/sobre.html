Ambiente de laboratório simulando um cenário corporativo de produção.

SIEM/XDR

O Wazuh centraliza alertas de segurança, eventos de endpoints, autenticação, integridade de arquivos, Windows/Sysmon e Suricata.

NDR/IDS

O Suricata atua como sensor de rede, gerando alertas IDS/NDR enviados ao Wazuh através do arquivo eve.json.

Endpoint Windows

O Sysmon fornece telemetria de processos, command line, conexões de rede, DNS e eventos do Windows.

IA SOC

A aplicação Flask utiliza OpenAI API para gerar análises, relatórios, playbooks, correlação e mapeamento MITRE ATT&CK.

Objetivo

O objetivo do projeto é demonstrar como um ambiente SOC pode utilizar Wazuh, Suricata, Sysmon e Inteligência Artificial para reduzir o tempo de triagem, apoiar a investigação inicial e gerar documentação técnica de incidentes.

Funcionalidades Implementadas

  • Login simples para acesso ao AI SOC Assistant.
  • Chat interativo com IA para perguntas sobre alertas.
  • Integração com Wazuh Indexer via API/OpenSearch.
  • Coleta de alertas Suricata, SSH, FIM, Windows e Sysmon.
  • Dashboard NDR com alertas de rede.
  • Dashboard Windows/Sysmon para análise de endpoint.
  • Relatório SOC automatizado.
  • Playbook de resposta a incidente.
  • Correlação de eventos com hipótese de cadeia de ataque.
  • Mapeamento MITRE ATT&CK quando houver evidência suficiente.
  • Histórico persistente em SQLite com nome do analista.
  • Download de relatórios, playbooks, correlação, Sysmon e alertas JSON.

Fluxo de Operação

1. Wazuh coleta alertas de Linux, Windows, Suricata e FIM.
2. A aplicação Flask consulta o índice wazuh-alerts-*.
3. Os eventos são normalizados em Python.
4. A IA recebe os alertas recentes como contexto.
5. O analista pode gerar relatório, playbook, correlação ou análise Sysmon.
6. A consulta é salva no SQLite com data, tipo, pergunta, resposta e analista.
7. Os relatórios podem ser baixados como evidência.

MITRE ATT&CK

O projeto realiza mapeamento básico para MITRE ATT&CK com base nos eventos observados. O mapeamento é utilizado para melhorar a explicação técnica e a priorização da resposta.

T1110 - Brute Force T1046 - Network Service Discovery T1059.001 - PowerShell T1059.003 - Windows Command Shell T1105 - Ingress Tool Transfer T1070 - Indicator Removal T1112 - Modify Registry T1049 - System Network Connections Discovery

Componentes Monitorados

  • Suricata: tráfego de rede, scans, ICMP, DHCP, assinaturas IDS.
  • SSH: autenticação, usuários inexistentes e brute force.
  • FIM: criação, alteração, permissão e exclusão de arquivos.
  • Sysmon: processos, command line, conexões, DNS e eventos Windows.
  • Active Response: resposta automática, como bloqueio por iptables.

Valor para um SOC

O sistema não substitui o analista, mas atua como apoio para acelerar a triagem, organizar evidências, sugerir hipóteses, gerar playbooks e documentar a investigação.

O fluxo final representa: 

Detectar → Correlacionar → Analisar com IA → Gerar Playbook → Exportar Evidência → Auditar Histórico
